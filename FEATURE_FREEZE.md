# Feature freeze (post-PH9)

After **Phase 9 — Daily Puzzle + Streak**, this product enters a **feature freeze** for the first RuStore release of **Переливайка**.

## Remaining release work (not PH9)

- Physical Android QA
- Release audit (permissions, dependencies, listing copy)
- Production AAB
- Screenshots / RuStore listing
- RuStore submission

Do **not** add new gameplay systems (coins, shop, cloud sync, streak achievements, etc.) before the first release unless a critical blocker requires it.
